---
description: Workflow complet pour créer et gérer une Saga (Série)
---

Voici les étapes pour créer une série avec continuité narrative et casting permanent dans Sketch-Pilot :

### 1. Initialisation de la Saga
1. Rendez-vous sur le **Dashboard**.
2. Cliquez sur le bouton **"+"** ou **"Nouvelle Saga"** (en haut à droite du sélecteur de mode).
3. Remplissez les informations de base :
   - **Nom de la Série** : Un titre évocateur (ex: "Les Chroniques de Mars").
   - **Bible Narrative** : Décrivez l'univers, le ton et les enjeux globaux. L'IA utilisera cela comme "mémoire" pour chaque épisode.

### 2. Casting des Personnages
Dans la même modal de création :
1. Dans la section **Casting**, ajoutez vos personnages récurrents.
2. Pour chaque personnage :
   - Saisissez son **Nom** (utilisez le même nom dans vos futurs prompts).
   - Ajoutez une **Description** physique ou psychologique.
   - Cliquez sur l'icône **Avatar/Ref.** pour ouvrir le **Character Studio** et lier un modèle visuel spécifique (pour garantir que le personnage se ressemble dans tous les épisodes).
3. Cliquez sur **Ajouter au casting**.
4. Une fois le casting terminé, cliquez sur **Créer la Saga**.

### 3. Génération du Premier Épisode
1. Sur le Dashboard, assurez-vous que le mode est réglé sur **"Série"** dans le sélecteur central.
2. Sélectionnez votre nouvelle Saga dans la liste déroulante juste en dessous.
3. Saisissez le sujet de votre premier épisode dans le champ de texte principal.
4. Cliquez sur **Générer**.

### 4. Edition et Validation (Studio)
1. Une fois le script généré, vous arrivez dans le **Studio**.
2. Dans la barre latérale droite (**Storyboard**), vous verrez une nouvelle section **"Contexte Saga"**.
3. Déroulez les onglets **"Bible Narrative"** et **"Casting"** pour vérifier que l'IA a bien respecté vos consignes.
4. Modifiez les scènes si nécessaire et lancez la génération finale.

### 5. Suite de la Série (Épisodes suivants)
1. Lorsque l'épisode 1 est terminé, le système extrait automatiquement un **résumé narratif** et met à jour l'état des personnages.
2. Revenez sur le Dashboard, sélectionnez la même Saga et générez l'épisode 2.
3. L'IA injectera automatiquement le résumé de l'épisode 1 dans le contexte du nouvel épisode, créant une continuité naturelle (Cliffhangers, évolution des intrigues).
